# 正交双极化微带贴片 AoA 定位天线示例

本目录给出一个用于 AoA（Angle of Arrival，到达角）定位的正交微带天线参考方案。它是概念级原型，便于沟通结构、端口、阵列几何和 PCB 摆放，不应直接作为量产 Gerber 使用；打样前需要用 HFSS、CST、ADS Momentum、openEMS 等工具做电磁仿真和实测调谐。

## 设计目标

- 应用：2D AoA 定位、蓝牙/Wi-Fi 2.4 GHz 频段定位原型。
- 中心频率：2.45 GHz。
- 阵列形式：2 x 2 方形阵列。
- 极化形式：每个贴片提供两个正交馈电点，分别作为 X 极化和 Y 极化端口。
- AoA 方式：通过相邻贴片之间的相位差估计入射方向。

## 建议叠层与尺寸

| 参数 | 示例值 | 说明 |
| --- | ---: | --- |
| PCB 外形 | 150 mm x 150 mm | 2 x 2 阵列和边缘连接器留量 |
| 介质 | FR-4 | `epsilon_r ~= 4.4`，损耗偏高，仅适合低成本原型 |
| 厚度 | 1.6 mm | 常见双层板厚 |
| 铜厚 | 35 um | 1 oz copper |
| 地平面 | Bottom 整面铺地 | 顶层非天线区域也可铺地并打过孔围栏 |
| 贴片尺寸 | 30 mm x 30 mm | 双极化方形贴片初值 |
| 阵元间距 | 61.2 mm | 约等于 2.45 GHz 自由空间半波长 |
| 馈电 | 50 ohm 微带线或探针馈电 | 两个端口相互正交，馈线需等长校准 |

2.45 GHz 自由空间波长约为：

```text
lambda0 = c / f = 3e8 / 2.45e9 ~= 122.4 mm
d = lambda0 / 2 ~= 61.2 mm
```

阵元间距不建议大于半波长，否则大角度入射时容易出现栅瓣和角度歧义。

## 端口定义

每个贴片有两个正交端口：

- X-pol：沿 X 方向馈电，用于测量 X 轴阵列基线相位差。
- Y-pol：沿 Y 方向馈电，用于测量 Y 轴阵列基线相位差。

如果接收机只有 4 个同步通道，可以先只使用同一种极化，例如四个 X-pol 端口；如果有 8 个同步通道，X-pol 和 Y-pol 可同时采集，用于极化分集或多径抑制。

## AoA 相位关系

对相邻阵元，理想远场窄带信号满足：

```text
Delta_phi_x = 2*pi*d/lambda * sin(theta_x)
Delta_phi_y = 2*pi*d/lambda * sin(theta_y)
```

因此：

```text
sin(theta_x) ~= lambda * Delta_phi_x / (2*pi*d)
sin(theta_y) ~= lambda * Delta_phi_y / (2*pi*d)
```

实际系统应做以下校准：

1. 每个 RF 通道的固定相位偏差。
2. 馈线长度差和连接器相位差。
3. 贴片之间的互耦。
4. PCB 介质常数误差与制造公差。
5. 外壳、电池、屏蔽罩对天线方向图的扰动。

## 调试建议

- 优先用 VNA 测量每个端口的 S11，目标可先设为 `S11 < -10 dB @ 2.45 GHz`。
- 测量同一贴片两个正交端口的隔离度，目标可先设为 `S21 < -15 dB`，更好的设计应接近或超过 20 dB。
- 四个同极化端口的馈线应做相位匹配；AoA 算法中再用标定矩阵补偿残余误差。
- 若需要更高效率和更稳定相位，建议把 FR-4 换成 Rogers RO4350B、RO4003C 等低损耗材料，并重新计算贴片尺寸。
